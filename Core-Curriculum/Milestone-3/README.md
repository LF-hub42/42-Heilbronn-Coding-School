# Milestone 3 — Codexion

Codexion is a Core Curriculum C project exploring concurrent programming with POSIX threads.
It covers thread synchronization and shared-resource coordination, with FIFO
and Earliest Deadline First (EDF) scheduling.

See the [Codexion repository](https://github.com/LF-hub42/Codexion) for the
project source and documentation.
