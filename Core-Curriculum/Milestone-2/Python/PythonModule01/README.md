# 🌱 Code Cultivation

## 📌 Description

Code Cultivation is a Python project from the 42 curriculum focused on
Object-Oriented Programming.

The project builds on the Python fundamentals from the previous module and
introduces a more structured way of working with data and programs.

The exercises are based around a digital community garden and gradually build
a small garden management system.

The project focuses on:

- Python program structure
- Object-Oriented Programming
- Classes and objects
- Reusable code
- Data organization
- Data integrity
- Extensible and scalable code structures

Each exercise builds on the previous one and introduces new concepts while
keeping the same garden theme.

## Instructions

The project uses **Python 3.10+**.

Each exercise has its own file and directory.

The project follows the naming conventions:

- Classes use `PascalCase`
- Functions and variables use `snake_case`

All functions and methods must include type hints and can be checked with
`mypy`.

The code should also follow the `flake8` standards and all programs should run
without errors.

Simple test code can be placed at the bottom of each file using:

```python
if __name__ == "__main__":
```

## 🌱 Exercises

### Exercise 0 — Planting Your First Seed

`ft_garden_intro`

The first exercise introduces the basic structure of a Python program.

The program stores information about a plant using simple variables:

- Name
- Height
- Age

The information is displayed using `print()`.

The program is executed directly with:

```bash
python3 ft_garden_intro.py
```

The exercise also introduces the special:

```python
if __name__ == "__main__":
```

pattern, which makes it possible to control what happens when a Python file is
executed directly.

### Exercise 1 — Garden Data Organizer

This exercise begins the Object-Oriented Programming part of the project.

The garden data is organized using classes instead of only using individual
variables.

### Exercise 2 — Plant Growth Simulator

This exercise continues working with objects and builds on the concepts
introduced in the previous exercise.

The goal is to model plant growth using an object-oriented approach.

### Exercise 3 — Plant Factory

This exercise continues the garden system by introducing reusable ways of
creating plant objects.

The focus is on making the code easier to reuse and extend.

### Exercise 4 — Garden Security System

This exercise focuses on protecting data and controlling how it can be accessed
or changed inside the garden system.

### Exercise 5 — Specialized Plant Types

This exercise builds on the existing classes by introducing specialized types
of plants.

It focuses on extending existing structures while keeping shared behaviour.

### Exercise 6 — Garden Analytics

The final exercise brings the previous concepts together to work with garden
data and produce useful information from it.
