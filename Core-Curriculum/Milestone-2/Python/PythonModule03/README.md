# 🎮 Data Quest

## Description

Data Quest is a Python project from the 42 curriculum focused on mastering
Python collections.

The project takes a game data scenario and uses it to explore different ways of
storing, accessing, and processing data.

The main idea is to understand that choosing the right data structure can make
a big difference in how a program performs. A simple structure can work well
with a small amount of data, but operations such as checking whether something
is already present can become much more expensive when they are repeated at a
larger scale.

The project contains seven exercises, starting with basic collection handling
and gradually working towards more advanced data processing.

## Instructions

The project is written in **Python** and follows the general requirements of
the 42 curriculum.

Each exercise is provided separately and focuses on a specific problem involving
Python collections and game data.

The code should be written clearly and should demonstrate an understanding of
the collection types and techniques used in each exercise.

## 🎮 Exercises

### Exercise 0 — Command Quest

`Command Quest`

The first exercise introduces the project through game-related data and Python
collections.

The focus is on working with structured data and understanding how collections
can be used to represent information in a program.

### Exercise 1 — Score Cruncher

`Score Cruncher`

This exercise focuses on processing game score data.

The goal is to work with a collection of values and extract or calculate useful

### Exercise 2 — Position Tracker

`Position Tracker`

The focus is on storing and processing related values using an appropriate

### Exercise 3 — Achievement Hunter

`Achievement Hunter`

This exercise deals with game achievements and collection-based data

### Exercise 4 — Inventory Master

`Inventory Master`

### Exercise 5 — Stream Wizard

`Stream Wizard`

### Exercise 6 — Data Alchemist

`Data Alchemist`

## 🧠 What I Learned

This project helped me understand that data structures are not just different
ways of storing information. The choice of collection can also affect the

During the project I worked with:

- Python collections
- Lists

- Iterating over collections
- Searching and checking data
- Processing structured data
- Choosing suitable data structures
- Working with larger amounts of data

One of the main ideas behind the project is that **your data structure is your
algorithm**.

For example, a sequential structure such as a list can require checking
elements one by one. Hash-based structures such as sets and dictionaries can
make certain lookup operations much more efficient.

## 🔧 Technical Focus

The project focuses on understanding when different Python collection types are
useful.

### Lists

Lists are useful for ordered collections where the elements can be accessed by
their position.

### Tuples

Tuples can be used to group related values together when the grouped data should
remain fixed.

### Sets

Sets are useful when uniqueness matters and when fast membership checks are
needed.

### Dictionaries

Dictionaries store data using key-value pairs and are useful when information
needs to be accessed through a specific key.

The exercises provide different situations where choosing an appropriate
collection makes the code simpler and more efficient.
