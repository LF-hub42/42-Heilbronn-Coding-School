# C Piscine C 00

*This project has been created as part of the 42 curriculum by ekypraio.*

## Description

C 00 was my introduction to programming in C during the 42 Piscine.

The exercises focused on writing simple functions, using loops and
conditions, and producing output with the `write` system call.

This repository contains the exercises I completed during my Piscine.

## Exercises

### ex00: ft_putchar

Created a function that writes a single character to standard output.

```c
void ft_putchar(char c);
```

**Focus:** Characters, functions and `write`.

### ex01: ft_print_alphabet

Created a function that prints the lowercase alphabet from `a` to `z`.

```c
void ft_print_alphabet(void);
```

**Focus:** Loops and character manipulation.

### ex02: ft_print_reverse_alphabet

Created a function that prints the lowercase alphabet in reverse order.

```c
void ft_print_reverse_alphabet(void);
```

**Focus:** Loops and reverse iteration.

### ex03: ft_print_numbers

Created a function that prints all digits from `0` to `9`.

```c
void ft_print_numbers(void);
```

**Focus:** Loops and character output.

### ex04: ft_is_negative

Created a function that checks the sign of an integer.

It prints `N` for a negative value and `P` otherwise.

```c
void ft_is_negative(int n);
```

**Focus:** Conditions and integer comparison.
