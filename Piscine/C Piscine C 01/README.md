# C Piscine C 01

*This project has been created as part of the 42 curriculum by ekypraio.*

## Description

C 01 introduced pointers and basic memory manipulation in C.

The exercises focused on accessing values through pointers, modifying
variables, working with arrays and implementing basic utility functions.

This repository contains the exercises I completed during my Piscine.

## Exercises

### ex00: ft_ft

Created a function that sets the value of an integer to `42` through
a pointer.

```c
void ft_ft(int *nbr);
```

**Focus:** Basic pointers and dereferencing.

### ex01: ft_ultimate_ft

Used multiple levels of pointers to access and modify an integer.

```c
void ft_ultimate_ft(int *********nbr);
```

**Focus:** Multiple pointer indirection.

### ex02: ft_swap

Created a function that swaps the values of two integers.

```c
void ft_swap(int *a, int *b);
```

**Focus:** Pointers and value manipulation.

### ex03: ft_div_mod

Created a function that calculates division and modulo and stores the
results through pointers.

```c
void ft_div_mod(int a, int b, int *div, int *mod);
```

**Focus:** Arithmetic and pointer parameters.

### ex04: ft_ultimate_div_mod

Created a function that replaces two integer values with their division
and remainder.

```c
void ft_ultimate_div_mod(int *a, int *b);
```

**Focus:** Pointer manipulation and arithmetic.

### ex05: ft_putstr

Created a function that prints a string using `write`.

```c
void ft_putstr(char *str);
```

**Focus:** Strings, pointers and character output.

### ex06: ft_strlen

Created a function that calculates the length of a string.

```c
int ft_strlen(char *str);
```

**Focus:** String traversal and pointers.

### ex07: ft_rev_int_tab

Created a function that reverses an integer array.

```c
void ft_rev_int_tab(int *tab, int size);
```

**Focus:** Arrays, indexing and swapping values.

### ex08: ft_sort_int_tab

Created a function that sorts an integer array in ascending order.

```c
void ft_sort_int_tab(int *tab, int size);
```

**Focus:** Arrays, comparisons and sorting.
