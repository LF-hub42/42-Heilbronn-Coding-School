# 42 Piscine

*This project has been created as part of the 42 curriculum by ekypraio.*

## About

This repository contains projects and exercises I completed during my
C Piscine at 42 Heilbronn.

The Piscine is an intensive introduction to programming and the Unix
environment. It combines practical exercises, peer learning and
independent problem solving.

This repository preserves my work from that period and documents my
first steps with C, Shell and Git.

## Projects

### Shell 00

Introduction to the Unix shell and command line environment.

Topics included:

- Files and directories
- File permissions
- TAR archives
- SSH
- Git
- Basic shell commands

Completed exercises in this repository: `ex00` to `ex06`

### Shell 01

Introduction to shell scripting and combining Unix tools.

Topics included:

- Shell scripts
- Pipes
- Environment variables
- `find`
- `grep`
- `awk`
- `tr`
- `wc`

Completed exercises in this repository: `ex01` to `ex06`

### C 00

My first exercises in C programming.

Topics included:

- Basic C syntax
- Functions
- Loops
- Conditions
- Characters and integers
- The `write` system call

Completed exercises in this repository: `ex00` to `ex04`

### C 01

Introduction to pointers and basic data manipulation.

Topics included:

- Pointers
- Pointer indirection
- Strings
- Arrays
- Swapping values
- Sorting

Completed exercises in this repository: `ex00` to `ex08`

### C 02

String and character manipulation in C.

Topics included:

- String copying
- ASCII
- Character validation
- Uppercase and lowercase conversion
- String traversal

Completed exercises in this repository: `ex00` to `ex09`

### C 03

Reimplementation of common string operations.

Topics included:

- String comparison
- String concatenation
- Substring searching
- Buffer sizes
- Pointer traversal

Completed exercises in this repository: `ex00` to `ex05`

## What I Learned

The Piscine gave me the foundation for my continued studies at 42.

During these projects I learned how to:

- work confidently in a Unix terminal
- use Git for version control
- write and execute shell scripts
- understand the fundamentals of C
- work with pointers, arrays and strings
- debug small programs
- read technical documentation
- solve programming problems independently
- learn through peer evaluation and collaboration

Most importantly, the Piscine introduced me to the problem solving
approach that I continued using throughout the 42 curriculum.
